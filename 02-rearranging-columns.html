Rearranging columns

Asking for the columns, and what comes out.

C-c r a (csv-rearrange-columns) asks Columns from $0 ($0,$2,$1"text"):. Type the columns as awk's print writes them, counted from 0, separated by commas, and press RET. An empty answer changes nothing.

For example, this answer on a file of five columns:

$0,$1,$3,$4"cent","hello"

leaves out the third column ($2), joins cent to the value of the fifth column, and adds a sixth column, now the fifth, that holds hello:

a,b,c,d,e   ->   a,b,d,ecent,hello

2.1 What a column can be

Each column is made of one or more parts, written side by side with nothing between them. Spaces between columns are ignored.

  • $N is column N, counted from 0.
  • $NF is the last column of each record. The last column is not the same number on every record, so $NF follows the record.
  • $* is the whole record. Alone, its columns stay its own, so the record is copied as it is. Joined to other parts, it is one column that holds the record's text as written.
  • "text" is text as it stands. Inside it, \" is a quote and \\ is a backslash.

Parts side by side are joined into one column, as in $4"cent" or $2" "$0, which puts the third column, a space and the first column in one column.

An answer that is not understood stops the command with a message that says where in the answer it went wrong. Nothing is changed. The messages are A $ needs a number, NF or *, A quote is left open and Not understood.

2.2 How a column is written

A column made of one field alone is written exactly as it stood, with its quotes if it had them.

A column joined from parts, or made of text, is written anew. It is put in quotes when it needs them: when it holds the separator, a quote or a line end, or begins or ends with a space. A quote inside it is doubled.

A column that a record does not have is empty, as in awk. The record a,b with the answer $0,$3 comes out as a,.

A byte-order mark at the start of the file stays at the start. It is not part of the first field.

2.3 Which lines

Every line is rearranged, the header too, as awk would. With a selection, only the lines it touches are. A line that comes out as it was is left alone and is not counted as rearranged.

When the command ends, the echo area says how many lines it rearranged. On an empty buffer, or a selection with no lines, it says No records to rearrange.

2.4 Undoing

The whole command is one step to undo, whatever the number of lines. Press u in modal editing, or the undo key of your editing style.
